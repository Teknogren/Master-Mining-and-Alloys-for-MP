# Master-Mining-and-Alloys-for-MP
An extension on the vanilla blacksmithing, metalworking and masonry system for MP servers, with the addition of a new skill: Mining.

This mod proposes new material Ores to be gathered using a new skill, integrated within the system, called Mining, granting the ability to get geological and minerals, locked and weighted, as the skill grows.

- Geological Branch (~90%):
    - Stones and Crushed Stones (~20% & 80%)
    - Dirt (~20%)
    - Sand (~15%)
    - Clay (~5%)
    - Limestone (~5%)
    - Sulfur (~2.5%)
    - Saltpeter (~2.5%)

- Mineral Branch (~10%):
    - Coal Ore (~30%)
    - Copper Ore (~25%)
    - Iron Ore (~15%)
    - Zinc Ore (~10%)
    - Aluminum Ore (~10%)
    - Tin Ore (~7.5%)
    - Lead Ore (~2.5%)

Additionally, it adds new recipes used in Construction, Blacksmithing and Weaponry.
- Make Pulverized versions of different materials using the Grindstone workstation.
- Fill Bags of Gravel, Sand & Dirt directly, without Tile destroying, to prevent MP Worlds to be ripped off.
- Make Bags of Cement Powder and Asphalt Mixture (if Buildworks mod installed), for Base building or Road making.
- Smelt minerals and Make alloys, using the Furnaces and Forges workstations, with newer Ingots and Sheets added.
- Craft Manmade Gunpowder, based at the principles of the historic Black Gunpowder.
- Make different Molds for Casings & Bullets to be used with the Handpress workstation.
- Craft Ammo Boxes, using a Handloading and Press technique.

If you think there are other missing recipes the devs should have added, let me know and I will consider adding them to this mod in the future. It adds currently, some QOL and some other missing recipes.

Box Mesh and the textures were created using Blender. This mod was created primarily for SpaghettiZ's Bolognese server but anyone is welcome to use it and repack it in their own server mods.
